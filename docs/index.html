How it works

Five steps, run every day

  1. Collect the data

    Team box scores, schedules and closing lines from the open hoopR NBA dataset: about 7,899 lined games since 2020, plus every game this season.

  2. Model team form

    Exponentially weighted offensive rating, defensive rating and pace with a 12 game half life, regressed 30% toward average between seasons, plus rest days and back to backs.

  3. Backtest walk forward

    Each season from 2021–26 is projected only from the games before it, then scored against final results and the closing line.

  4. Save the market

    A daily pull from The Odds API saves spreads, totals and moneylines across US sportsbooks before the evening slate, so every projection is graded against a real number.

  5. Publish and grade

    This site rebuilds itself every evening after the odds pull and every morning after the results, so each projection is posted before tip and graded after the final.
